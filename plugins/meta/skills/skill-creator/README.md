# skill-creator

Create, evaluate, and iterate on high-quality agent skills with structured guidance, quality scoring, and best-practice enforcement.

## Triggers

- "create a skill", "make a new skill", "build a skill for"
- "improve this skill", "optimize this skill", "this skill isn't working well"
- "evaluate this skill", "score this skill", "how good is this skill"
- "run evals on", "benchmark this skill", "test this skill's quality"
- "I keep doing X manually", "turn this into a skill"

## Prerequisites

- None (pure guidance skill, no external dependencies)

## Platform

Works on any agent that supports the Agent Skills standard (Claude Code, OpenCode, Cursor, etc.)

## Setup

No setup required. The skill provides procedural guidance for authoring and evaluating skills.
